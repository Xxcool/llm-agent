# ADR 0001：免登录工作区与免费容器部署

- 日期：2026-11-11
- 状态：已实施；线上发布与平台验收单独记录

## 约束与选择

访问者主要在中国大陆；托管预算为零；访客不需要授权登录，各自配置 API Key，不能读取其他浏览器的数据。沿用 React/FastAPI/SQLite，不迁移到另一种应用架构。

选择魔搭 Docker 创空间免费 CPU 作为试用目标。应用身份使用签名 HttpOnly Cookie，工作区分别拥有 SQLite、知识文件、配置与代码沙箱；所有对象查询都发生在当前工作区的存储实例内。无法辨别共用同一浏览器的人；清除 Cookie 后不提供找回或跨设备同步。

## 数据与安全

多租户不继承环境变量公共 Key；公开部署要求用户先配置自己的 Key。API Key 以 Fernet 加密保存，主密钥位于运行数据根目录并随备份保存。原明文配置可读取，在用户下次保存时以加密格式替换，不主动遍历或迁移现有私有资料。

默认 SQLite 运行于本地文件系统。对象存储挂载目录只接收完整快照，使用在线 backup API、压缩包哈希和最后发布的清单，恢复时校验完整性；失败可回退旧完整版本。备份失败通过健康状态暴露并定期重试。免费平台故障和突然终止仍可能导致最近写入丢失，不能用试用方案代替可靠存储承诺。

监控探针不创建工作区、不调用模型。浏览器先串行初始化 Cookie，再发并行 API 请求；闲置连接可释放，工作区数量有内存上限，已有磁盘数据不会自动删除。平台内嵌预览提示打开独立页面，以避免第三方 Cookie 限制。

原始 HTML 经白名单净化，Mermaid 使用严格模式并净化生成 SVG。富文本依赖延迟加载，保留安全图表、公式与媒体。

## 状态与交付

确认一个候选会撤销其他候选的确认；代码审批重新检查所属方案和预览文件哈希。先在暂存目录校验全部文件，再替换目标；替换异常恢复本次已修改文件。

消息编辑／重新生成从数据库裁剪原分支。包含执行中或已完成任务的分支拒绝改写，避免破坏交付追溯。done 事件在消息持久化后发送。任务模型仍为人工逐项执行列表；不实现 DAG、业务命令执行或强制取消模型调用。重启遗留 running 状态改为 failed，允许重试。

## 部署边界

部署包按代码、构建产物和公开示例白名单生成，不打包任何运行数据。目标包含未知文件时拒绝覆盖，不删除旧部署资料。不开通付费算力，不启用 OAuth，不将用户 Key 写入镜像。
